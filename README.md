## Инструкция по запуску

Проект поддерживает два независимых сценария развертывания, которые разведены по разным сетевым портам для исключения конфликтов в операционной системе.
Накатывание миграций и сидинг данных срабатывают только при чистой базе данных, то есть при первом запуске.

### Сценарий 1. Запуск всего стека в Docker

Этот режим собирает и запускает все компоненты приложения (Бэкенд, Фронтенд, СУБД) в изолированных контейнерах.

1. Убедитесь, что порты `5180`, `5254` и `5433` свободны на вашем компьютере.
2. Выполните команду в директории QuizWebApp:
   ```bash
   docker compose up --build -d
   ```
3. После успешного поднятия контейнеров приложение доступно по адресам:
   * **Frontend (Интерфейс):** `http://localhost:5254`
   * **Backend API (Swagger/Эндпоинты):** `http://localhost:5180`
   * **PostgreSQL:** на порту `5433`

### Сценарий 2. Локальная отладка в IDE

Этот режим запускает в Docker только базу данных, позволяя запускать бэкенд C# и фронтенд Blazor непосредственно из IDE.

1. Убедитесь, что порты `5179`, `5253` и `5432` свободны на вашем компьютере.
2. Поднимите изолированный контейнер локальной базы данных, которая будет доступна на порту `5432`:
   ```bash
   docker compose -f docker-compose.infra.yml up -d
   ```
3. Откройте решение в вашей IDE и запустите проекты:
   * **Бэкенд API:** `dotnet run` (запустится на порту `5179`).
   * **Фронтенд Blazor:** `dotnet run` (запустится на порту `5253`).
4. Откройте в браузере локальный адрес интерфейса: `http://localhost:5253`.

### Очистка данных и сброс базы под ноль

* **Для Docker-стека:** `docker compose down -v`
* **Для Локальной базы:** `docker compose -f docker-compose.infra.yml down -v`

## Стек технологий

* **Backend API & Core:** .NET 10.0 (ASP.NET Core), Minimal APIs, JWT Bearer Authentication.
* **Backend Infrastructure & Database:** Entity Framework Core (EF Core), PostgreSQL.
* **Frontend:** Blazor WebAssembly (WASM), Bootstrap.
* **DevOps & Infrastructure:** Docker, Nginx (для раздачи статики WASM).

## Возможности системы

### Общий функционал

* Вход и регистрация в систему (разделение ролей: Организатор / Пользователь).

### Модуль Организатора (Админа)

* Просмотр краткой аналитической сводки на главной странице (Home).
* Просмотр списка и управление статусами зарегистрированных пользователей.
* Создание, редактирование и просмотр списка доступных тем квизов.
* Создание, редактирование и просмотр структуры квизов и связанных вопросов.
* Мониторинг истории попыток прохождения квизов.

### Модуль Участника (Пользователя)

* Просмотр списка доступных и активных квизов на главной странице (Home).
* Выбор квиза и его прохождение с контролем времени.
* Просмотр персональной истории попыток и результатов по всем пройденным квизам.
